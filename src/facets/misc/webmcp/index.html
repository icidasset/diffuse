WebMCP

Exposes Diffuse's facet tools to your browser's built-in AI agent. While this facet is open, the agent can list, read, create and update your facets.

Checking WebMCP support…

  • list-facets Enumerate your facets.
  • get-facet Read one facet, including its HTML source.
  • create-facet Save a new facet.
  • update-facet Edit an existing facet's code or metadata.
